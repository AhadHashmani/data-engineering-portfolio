### [`ecoli-geospatial`](./ecoli-geospatial)
Spatial risk analysis of E. coli exposure across Austin zip codes using 200K+ environmental records. Computes composite risk scores, identifies statistically high-risk zones, and flags EPA threshold exceedances. Independent capstone project advised by Prof. Timothy Keitt (Integrative Biology / Oden Institute, UT Austin).

**Stack:** Python, NumPy, pandas, SciPy

---

### [`numerical-methods`](./numerical-methods)
Implementations of root-finding algorithms (secant method) with empirical convergence rate analysis — linear and superlinear rates tracked per iteration. Includes visualization of error decay.

**Stack:** Python, NumPy, Matplotlib

---

### [`econometrics`](./econometrics)
OLS regression from scratch with HC3 heteroskedasticity-robust standard errors, VIF multicollinearity diagnostics, and residual analysis. No statsmodels — pure NumPy linear algebra.

**Stack:** Python, NumPy, SciPy, pandas
